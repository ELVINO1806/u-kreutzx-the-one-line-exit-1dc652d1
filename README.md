# The One-Line Exit

This repository holds a small Python program written for the make.fun competition "The One-Line Exit". The program produces exactly one line of a resignation letter: a single funny sentence that still reads as a proper goodbye to a job, and nothing more.

## What it does

Running `main.py` writes that one resignation line — a single line, between 1 and 140 characters long — to `/output/entry.txt`. The program uses only the Python standard library and needs no network access, so it runs the same way every time.

## How to run

```sh
python3 main.py
```

Then read the line at `/output/entry.txt`.
